# PSK Scanner Agent

Локальний Windows-агент для CRM PSK_RECRUTER і мережевого Canon MF212w.

## Призначення
- приймає команду сканування з веб-CRM через `http://127.0.0.1:8765`;
- відкриває системний WIA/TWAIN діалог Canon;
- зберігає кожен документ як PDF;
- підтримує послідовне сканування пакета: після кожного документа CRM може запустити наступне сканування;
- повертає CRM URL локального PDF для подальшого завантаження в Supabase та AI-розпізнавання.

## Вимоги
Canon MF212w має бути встановлений у Windows як сканер/WIA. Агент не містить секретів Supabase або OpenAI.
