# TRORECRUITER — Рішення проекту

## 2026-09-30 — Джерела правди
1. GitHub — код.
2. Supabase — дані та файли.
3. `docs/` — архітектура, правила, roadmap та прийняті рішення.
4. Чат — робоче обговорення; завершені рішення переносимо в `docs/`.

## 2026-09-30 — Документи
Використовуємо існуючий Supabase Storage та таблицю `documents`. Не створюємо дублікати через browser `localStorage`.

## 2026-09-30 — Перевірка документів
AI/OCR лише розпізнає та класифікує. Статус `Підтверджено`/`Перевірений` встановлюється після перевірки рекрутером.

## 2026-09-30 — Розробка
Не вносити ризикові зміни без перевірки фактичного стану `main`. Спочатку інвентаризація, потім точкова зміна, потім тест на реальному тестовому документі.
