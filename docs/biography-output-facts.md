# Автобіографія у послужному

За рішенням користувача прийняті записи автобіографії є джерелом відомостей особової справи. biography-facts.js створює спільне представлення для генератора послужного та перевірки його готовності.

Робота з bio_work_claims додається до представлення work_records без зміни збережених масивів Supabase. Зберігаються джерело, точність дат та початковий текст. Записи з requires_review, закреслені, без джерела чи з некоректними датами не використовуються. Перетин періоду того самого роботодавця з наявним записом не створює дубль; чинний запис має пріоритет. Дані освіти з автобіографії є fallback за відсутності прийнятих документальних записів освіти.

Місяць/рік друкуються без вигаданого дня. Подія роботи у поліції не перетворюється на військову службу через дубльований bio_service_claim. Чинні відповіді «не служив/не служила» та «не працював/не працювала» зберігають пріоритет.

Перевірено на погодженій справі: 4 періоди роботи, освіта, батьки та фраза про відсутність військової служби потрапляють у чинні поля. Створено PDF на 10 сторінках без зміни геометрії. Сторінки освіти й трудової діяльності оглянуті візуально. Зв’язок формування є динамічним: раніше збережений PDF потрібно сформувати повторно.

Тести: crm-biography-facts.cjs; модель послужного, готовність, реєстр полів, повторні записи й наскрізний сценарій. Міграція БД не потрібна. Вихідні дані й правки друку не перезаписуються.
