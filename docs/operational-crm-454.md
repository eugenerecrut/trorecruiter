# Операційний інтерфейс CRM — 1.1.0.454

## Послідовність роботи

1. **Дашборд**: обрати рекрутера, вид оформлення, пріоритет або пошук. У списку — кандидат, етап, наступна дія, контрольна дата, рекрутер, перевірений комплект.
2. **Рух справи**: записати наступну дію й дату на будь-якому етапі. Пауза — окрема ознака. Додаткові обстеження ВЛК мають контрольну дату.
3. **Картка V3**: компактна шапка з фото, контактом, відповідальним і видом оформлення. Паспорт — у «Основне»; документи — після «Освіта / робота».
4. **Документи**: завантажити / позначити наявність / перевірити. Вкладка картки використовує той самий менеджер, що й окремий екран.
5. **PDF**: пакет готовий лише за наявності підтверджених електронних копій. Позначка паперового документа виконує вимогу комплекту, але не створює сторінку PDF.

## Правила й технічні зміни

- `document-state.js` — спільний розрахунок вимог, перевірки, копій, умов та PDF-пакета для V2, V3, менеджера, дашборда й workflow.
- Мобілізаційні військово-облікові альтернативи рахуються як одна вимога; свідоцтво про зміну ПІБ не залежить від трудового досвіду.
- Для дітей кожен слот має окремий документ. Неуточнені умови показуються окремо й не трактуються як «ні».
- `case-information.js` — читання збереженої освіти, трудового стажу й служби для обов’язкової інформації. Явне «не працював / не служив» має пріоритет над старим OCR-текстом.
- Призначення рекрутера враховує `updated_at`, щоб не приховати одночасні зміни картки.
- PDF формується локально, із ПІБ у назві та відступом 35 мм зліва. Копії у сформованому пакеті розміщуються на сторінках із цим відступом; оригінали не перезаписуються. Чекбокси малюються векторно.
- V3 — початковий інтерфейс у цій версії. **«Повернути V2»** лишається у шапці; на телефоні — після **«Деталі»**. Вибір V2 зберігається локально. Новий ключ налаштування: `crm.candidateCard.version.454`.
- Схема Supabase, права доступу та AI merge не змінені. Масового оновлення кандидатів немає.

- Регресії: `crm-card-v3.cjs`, `crm-information-work.cjs`, `crm-education-summary.cjs`, `crm-archive-path.cjs` — PASS.

- Desktop 1440 px та mobile 390 px: компактна шапка, вкладки, документи й дашборд. Сканер прихований на телефоні.

## Межі перевірки

Архівування з видаленням оригіналів і запис повного PDF-пакета в робочий Supabase не запускалися. Перевірки запису виконувалися на синтетичних даних; робочі справи перевіряються читанням після публікації. Це не замінює контрольного оформлення та архівування реальної справи користувачем.
