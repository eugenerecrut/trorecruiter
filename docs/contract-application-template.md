# Заява на оформлення особової справи

Чистий односторінковий бланк A4 відтворено за наданим власником CRM зразком. Заголовок, надрукований текст, шість персональних пунктів, рядки військової частини, посади, ВОС, дати й підпису збережено. Рік залишено для ручного заповнення.

Заповнений скан не включений до репозиторію. Бланк не містить даних кандидата, військової частини з його заяви або підпису. Це відтворення зразка, а не окреме підтвердження офіційного затвердження форми.

Друк: A4, фактичний розмір 100%, без додаткових колонтитулів. Публічний файл: templates/contract-application-blank.pdf.
