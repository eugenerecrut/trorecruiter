## Наступні кроки
1. Спроєктувати й підключити серверне продовження до чинних jobs/координаторів, без паралельного writer.
2. Умови запуска: доручення активної людини; чинна версія/власник; дозволений тип; відсутність блокувальної невідповідності особи; явний бюджет; ідемпотентний parent/child зв’язок.
3. Синтетично перевірити: переривання між етапами, CAS, платіжну невизначеність, дублікати, повернення lease, пропуск архівних/замінених/AI-disabled джерел, продовження без браузера.
4. Після тестів і рев’ю публікувати погоджені зміни. Реальне приймання — лише після нового конкретного погодження.
