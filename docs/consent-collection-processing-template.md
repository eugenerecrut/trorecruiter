# Згода на збір та обробку персональних даних

Чистий бланк A4 відтворено за наданим власником CRM заповненим зразком. Збережено заголовок, перший текстовий блок про обробку даних, другий блок підтвердження проходження психодіагностичних методик і три місця для підписів.
