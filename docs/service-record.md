# Послужний список CRM

Модуль crm-service-record.js заповнює фіксований PDF-бланк templates/service-record/blank.pdf: 10 сторінок A4, дзеркальні поля, геометрія з погодженого зразка Перекопського. Порожній бланк не містить даних кандидатів. Незмінні блоки Совіна, жетон, пункт 19 і підписи збережені.

Кнопка: Рух справи → кандидат → Друк та пакети документів → Послужний список. Перед збереженням — редактор тексту для поточного PDF, перегляд та перевірка місткості кожного поля. Файл зберігається через чинний generated(), з ПІБ у назві та версією попереднього послужного. Перевіряється updated_at кандидата перед записом. Схема БД не змінюється.

Джерела: candidates, profile_data, personal_files. Записи освіти за роком; служба — work_records kind=military_service, цивільна робота — employment. requires_review виключає неперевірені записи. Призов не бере поточний service_type контракту як підставу попередньої служби. Наказ про звання — лише підтверджені military_rank_records. SHPK не використовується як звання. Порожні поля не вигадуються. Діти за явної позначки «немає» не друкуються. Адреса сім’ї лише family_residence_confirmed.

Погоджені друковані скорочення можуть зберігатися у profile_data.service_record_print (ключ поля), не замінюючи повні записи освіти/служби. Редактор модуля змінює лише поточний PDF, а не ці факти. Переповнення блокує збереження, автоматичного зменшення шрифту, обрізання чи додавання сторінок немає.

Збережені структуровані доповнення: military_oath, military_discharge, combat_records, awards, reserve_training_records, marriage_record.registration_authority, family_residence_address. Дані з цих ключів виводяться в редакторі послужного. Для роботи підписний блок знаходиться після записів у межах початкової сторінки; для відсутності роботи — після відповідного напису. Для відсутності служби — об’єднаний рядок і блок Совіна. До 29 періодів служби у початкових чотирьох сторінках; довгі записи потребують ручного скорочення.

Перевірка: node tests/crm-service-record.cjs. Локальні PDF-перевірки: Перекопський (5 періодів служби, 9 бойових, нагорода), чоловічі/жіночі формулювання відсутності роботи/служби, 10 сторінок, блокування переповнення; ручний огляд сторінок. Повний браузерний сценарій збереження у робочій CRM не запускався, щоб не створювати тестових документів кандидата.
