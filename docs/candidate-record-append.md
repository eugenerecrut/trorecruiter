# Доповнення структурованих даних кандидата

Новий незалежний диплом, період роботи або подія додається після перевірки джерела й упевненості AI. Збережені записи залишаються незмінними. Повторний запис не дублюється; відмінності всередині вже відомого запису передаються рекрутеру для звірки.

Освітній документ без загального full_name може використовувати єдине явно розпізнане owner_full_name зі своїх освітніх записів. Неоднозначний власник не обирається автоматично.

Родичі мають field_sources для окремих значень. Ручне редагування прибирає AI-позначку тільки зі зміненого поля, зберігаючи джерела решти даних. Значення null у field_sources позначає ручне значення.

## Розгортання

Потрібна міграція 20261016064203_append_candidate_document_records.sql після попередньої військової міграції. Обидві наразі підготовлені локально. Перед застосуванням повторно звірити чинне визначення RPC. Масова повторна синхронізація не запускається.

## Перевірки

- 38 JS-тестів: синхронізація, структуровані військові факти, картка V3, додавання записів.
- 16 сценаріїв ізольованого PostgreSQL: компіляція міграцій, незмінність старих записів, захист від застарілих даних, джерела родичів, активний працівник і RLS.
- 37 браузерних перевірок V3; 0 помилок JavaScript. Лише тестові записи.

Не перевірялося на робочих даних; локальні результати не означають публікацію.

## Суперечності з відповідями про роботу і службу

Новий період роботи та його події не переносяться автоматично, якщо в картці явно вказано worked_before=false. Аналогічно served_before=false захищає від автоматичного додавання нової служби. Система показує джерело суперечності рекрутеру; невідоме значення не прирівнюється до заперечення. Незалежні несуперечливі записи з того самого документа залишаються доступними для перенесення, а старі записи не видаляються.

Черга рекрутера не пропонує переносити попередній ai_extracted, поки повторне розпізнавання документа триває або завершилося помилкою. Для помилки залишається повторне розпізнавання.

Після цих змін: 42 JS-тести, 16 ізольованих SQL-сценаріїв і 37 браузерних перевірок пройдені.
