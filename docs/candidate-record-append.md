# Доповнення структурованих даних кандидата

Новий незалежний диплом, період роботи або подія додається після перевірки джерела й упевненості AI. Збережені записи залишаються незмінними. Повторний запис не дублюється; відмінності всередині вже відомого запису передаються рекрутеру для звірки.

Освітній документ без загального full_name може використовувати єдине явно розпізнане owner_full_name зі своїх освітніх записів. Неоднозначний власник не обирається автоматично.

Родичі мають field_sources для окремих значень. Ручне редагування прибирає AI-позначку тільки зі зміненого поля, зберігаючи джерела решти даних. Значення null у field_sources позначає ручне значення.
