🖨 PSK Scanner Agent

⚪ Перевірка агента…

Canon MF212w

PSK Scanner Agent — локальний компонент Windows, який забезпечує зв'язок між веб-CRM та мережевим сканером Canon MF212w. Браузер не має прямого доступу до локального WIA/TWAIN-сканера, тому агент працює як локальний посередник.

Що робить агент:

  • запускає сканування через встановлений у Windows сканер;
  • передає отриманий документ у CRM;
  • підтримує режим «Сканувати пакет»;
  • дозволяє після кожного документа натискати «Сканувати наступний документ»;
  • після завершення передає пакет на розпізнавання, класифікацію та збереження в Supabase.

Локальний агент: http://127.0.0.1:8765
Інтерфейс сканера: WIA/TWAIN
