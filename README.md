# TRORECRUITER

Статичний сайт рекрутингу українською мовою.

## Що всередині
- адаптивна головна сторінка;
- напрями служби;
- блок переваг;
- покроковий процес;
- форма заявки;
- FAQ.

## Запуск
Відкрийте `index.html` у браузері.

## Важливо
Не вставляйте секретні ключі або webhook-ключі безпосередньо у `index.html`/`script.js`.
Для прийому заявок підключимо серверний endpoint або CRM на наступному етапі.
